# Project G Free-First News Collection Policy

## Decision

Project G will begin with zero recurring API cost.

Paid news and social-media APIs will not be introduced until the content-processing and publishing workflow has demonstrated sufficient value.

## Initial workflow

1. A human discovers a relevant Giants article or announcement.
2. The article URL is submitted to Project G.
3. Project G records source metadata and checks for duplicates.
4. Project G evaluates Giants relevance.
5. Later stages create a summary, fan commentary, and content scripts.

## Automated collection rules

Automated collection is permitted only when:

- the provider explicitly permits it;
- an official free API or feed is available;
- access controls are not bypassed;
- collection remains within configured rate and size limits;
- article bodies, images, and videos are not copied unnecessarily.

## Giants official news

Giants Official News remains a primary confirmation source.

Automated collection is paused because transparent Project G requests received HTTP 403 responses.

Project G will not use:

- browser impersonation;
- copied browser cookies;
- CAPTCHA avoidance;
- proxy rotation intended to bypass restrictions;
- authentication or access-control circumvention.

## Paid services

X API and other paid services may be reconsidered after:

- the manual intake workflow operates successfully;
- content quality has been validated;
- regular publishing is sustainable;
- a clear monthly budget has been approved.

## Current target

- Recurring collection cost: 0 yen
- Manual discovery work: no more than 5 minutes per day
- Automated processing after URL submission: as much as practical
- External publishing: disabled until later approval
